# Firmware del sistema de control

Esta carpeta contiene el código del microcontrolador y la IA en el borde.

---

## Estructura

- `/ia_control/` — Código de la IA (TensorFlow Lite Micro).
- `/sensores/` — Código para sensores de presión, flujo y acelerómetro.

---

## Estado actual

🔲 Pendiente de desarrollo.  
🔲 El diseño conceptual está definido, pero el código está por escribir.

---

## Requisitos

- Microcontrolador: STM32L o MSP430.
- Compilador: ARM GCC o IAR.
- Dependencias: TensorFlow Lite Micro, CMSIS-DSP.
