# Archivos CAD del prototipo

Esta carpeta contiene los archivos CAD (diseño asistido por computadora) del prototipo del corazón artificial híbrido.

---

## Estructura

- `/stl/` — Archivos STL para impresión 3D.
- `/step/` — Archivos STEP para software CAD profesional.
